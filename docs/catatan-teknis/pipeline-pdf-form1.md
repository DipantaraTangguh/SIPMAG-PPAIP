# Pipeline PDF Form 1 — Surat Keterangan
Form 1 "surat keterangan memenuhi syarat akademik" PDF now uses the same DOCX+LibreOffice path as [Pipeline PDF Form 2](pipeline-pdf-form2.md) (migrated off dompdf 2026-07-06). `PdfService::downloadForm1ApprovalLetter` maps student/kaprodi data to `<<placeholder>>` keys and calls `DocxToPdfRenderer::render(public_path('assets/template-form-1.docx'), ...)`, returning 503 when soffice missing. dompdf import, the `logoSource/assetImageSource/imageDataUri` helpers, and `resources/views/pdf/surat-keterangan.blade.php` were deleted.

Template built from user's `Template-Form1.docx`: dotted-line fills + split "[Tanggal Pengajuan]"/"Nama Lengkap Mahasiswa"/"Nama Lengkap Kaprodi" text were rewritten into 11 single-run placeholders (`<<Nama Kaprodi>>`, `<<Program Studi>>`, `<<Nama Mahasiswa>>`, `<<NIM>>`, `<<Semester>>`, `<<Jumlah SKS>>`, `<<IPK>>`, `<<Rencana Magang>>`, `<<Tanggal Pengajuan>>`, `<<Tanggal Persetujuan>>`, `<<NIDN>>`). `<<Program Studi>>` intentionally appears 3× (recipient + field + kaprodi block) — strtr fills all with study_program. UB logo stays baked in the docx header (rId1 in header1.xml); no logoSrc needed. Field "Rencana pelaksanaan magang" maps to `skemaMagang` only (docx has 7 field rows, dropping the old topik/output rows).

**Signatures:** wet signatures are prohibited, so both signature gaps hold a STATIC green Lucide `check` badge (green filled circle + white check) baked into the template as `word/media/image2.png` (rId100), NOT dynamic data. Generated by rasterizing an SVG via `soffice --convert-to png` (no Pillow/rsvg on this machine; only `sips`). Checks are 731520 EMU (0.8in) and horizontally centered over each signer's column.

**Layout revisions (2026-07-06):** the original 2-col borderless field table was replaced with tab-stop paragraphs (`<w:tab w:pos="3969">`, format `Label<tab>:  <<value>>`) so colons align in one column. The student "Jakarta, <date>" and "Hormat saya," are now two rows (a `<w:br/>` between them). Because the bigger checks + break overflowed to a 2nd page, four empty spacer paragraphs (paraIds 7BD808C3 student; 19AD9231/78F2E2F2/312C5B9D kaprodi) are deleted to keep it on one page.

**Cara memakainya:** placeholders are stored XML-escaped in document.xml as `&lt;&lt;X&gt;&gt;` (the renderer xmlEscapes both search key and value). If the template is re-saved in Word, runs may split and break placeholders/the embedded check — rebuild from the scratchpad `build_template.py` approach (positional replace of pure-ellipsis `<w:t>…+</w:t>` runs + exact multi-run substring swaps) rather than editing in Word.
