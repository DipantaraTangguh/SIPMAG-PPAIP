# Catatan Teknis

Sebab, jebakan, dan keputusan desain yang **tidak terbaca dari kode**. Kode bisa
dibaca ulang kapan saja; alasan di baliknya tidak.

Isinya berasal dari sesi kerja nyata — tiap catatan ditulis setelah sesuatu
rusak, diselidiki, lalu diperbaiki. Baca yang relevan sebelum menyentuh area
yang bersangkutan.
